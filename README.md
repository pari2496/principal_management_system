# Principal Management System

A Python-based desktop application built using Tkinter to support school administration and help organise routine tasks in a single graphical interface.

**Project Status:** In Development

## Project Overview

The Principal Management System is a desktop software project developed for a school administration use case at Jatindera Green Field School.

The application aims to simplify selected administrative workflows, including teacher task management, meeting organisation, and maintaining records related to student misbehaviour and warnings.

Built with Python and Tkinter, the project focuses on providing a straightforward graphical interface for school-related administrative activities.

## Objectives

- Simplify routine school administration.
- Organise teacher-related tasks and responsibilities.
- Manage meeting-related information, including dates and times.
- Maintain records related to student misbehaviour and warnings.
- Explore practical desktop application development using Python.

## Technology Stack

- **Python** — Application logic and functionality.
- **Tkinter** — Graphical user interface (GUI).

## Getting Started

### Prerequisites

- Python 3 installed on your computer.
- Tkinter support in your Python installation.

### Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd PrincipalManagementSystem
```

### Run the Application

On Windows:

```bash
py main.py
```

Alternatively:

```bash
python main.py
```
